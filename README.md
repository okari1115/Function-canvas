# Function Canvas v5 — 機能マップ / 階層表示

## v5で追加
- 機能マップ：入力解析・検証、ソート制御、操作実行、履歴・最適化、出力・計測、初期化・後始末、その他・共通に候補分類。
- ZIPに加え、以前添付された `archive.tar.gz` も直接取り込み可能です（ブラウザの `DecompressionStream` 対応が必要）。
- グループを選ぶと「主要関数」の呼び出し関係を確認でき、static補助関数は展開・折りたたみできます。
- 機能グループ間の依存は1本の線に集約し、関数マップ内ではグループ内の呼び出しを可視化。他グループへの依存件数も表示。
- 関数を選択して「選択関数に集中」で前後1〜2段階に絞り込めます。
- 関数の所属グループは名前・ファイル名からの**推定**です。右側の設計メモで自由に手動変更できます。手動変更は再解析後も保持します。
- 従来の「通常キャンバス」を残し、すべての接続のドラッグ作成・付け替え、削除、移動、手書きメモ編集が可能です。
- ノードをクリックしただけでは座標更新しないよう6pxの移動しきい値を設定。座標の固定上限を外し、ノードを動かすとキャンバスの幅・高さが拡張されます。
- 1プロジェクトJSON保存にソース・言語・表示設定も含め、再読込して編集を続けられます。全プロジェクト保存も従来どおりです。

## 構文解析について（正確性の境界）
この版は**ローカルの軽量ソース解析器**を使います。Tree-sitterのWASMは今回の配布には**含まれていません**。外部パッケージを検証可能な形で同梱できないためです。無理にオンラインのCDNへ依存するとPWAのオフライン動作が不安定になるため、C/Python双方ともネットワーク不要で動く方式を採用しています。解析エンジンは `parser.js` に分離し、将来的にTree-sitterへ差し替えられます。

Cの関数定義と直接呼び出し、`static` は大部分の普通の構文で認識できます。ただし、関数ポインタ、マクロ、条件付きコンパイル、重複名、プリプロセッサで生成したコードなどは正確に解決できません。Pythonの動的呼び出しやクロスモジュールの名前解決も保守的に未解決とします。**「分類」は意味を理解した確定判断ではなく、根拠付きの候補です。**

## GitHub Pagesの更新
更新前に「全プロジェクトを保存」でJSONバックアップしてください。
ZIPに含まれる `index.html`, `parser.js`, **`classifier.js`（新規）**, `jszip.min.js`, `sw.js`, `manifest.webmanifest`, アイコンPNG3つをリポジトリのルートに配置します。前バージョンからの更新では `classifier.js` が**必須**です。

Safariとホーム画面PWAの保存領域が別になる場合があります。JSONで移してください。更新後、古いバージョンのキャッシュが残る場合はSafariで公開ページを更新してホーム画面版を再起動してください。

`single.html` と `Function Canvas v5 portable.html` は単一HTMLの確認用です。PWA公開には `index.html` と他のファイルを使ってください。

第三者ライブラリJSZipのライセンスは `JSZip_LICENSE.md` を参照してください。
